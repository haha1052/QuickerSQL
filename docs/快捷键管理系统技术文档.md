# 统一快捷键管理系统技术文档

## 一、概述

统一快捷键管理系统（Unified Shortcut System）是 QuickerSQL 的核心功能模块之一，为应用提供统一的、可配置的快捷键管理能力。

**版本**：v1.2
**日期**：2026-06-28
**状态**：20 个快捷键全部 100% 实现

---

## 二、架构设计

### 2.1 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                        Settings 系统                         │
│                   (__settings 表存储)                        │
└─────────────────────────────┬───────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                  shortcutManager (核心)                      │
│  ┌──────────────────┐  ┌──────────────────┐                 │
│  │  命令注册中心      │  │  快捷键绑定中心   │                 │
│  │  (command ID +   │  │  (keyString +    │                 │
│  │   handler)       │  │   command ID)    │                 │
│  └──────────────────┘  └──────────────────┘                 │
│  ┌──────────────────┐  ┌──────────────────┐                 │
│  │  字符串解析       │  │  冲突检测         │                 │
│  │  (parseShortcut) │  │  (findConflicts) │                 │
│  └──────────────────┘  └──────────────────┘                 │
└──────────────────────┬──────────────────────┬───────────────┘
                       │                      │
                       ▼                      ▼
        ┌──────────────────────┐   ┌──────────────────────┐
        │   ShortcutProvider   │   │   SQLEditor 集成      │
        │   (全局快捷键)        │   │   (编辑器快捷键)      │
        └──────────────────────┘   └──────────────────────┘
```

### 2.2 作用域（Scope）

快捷键分为两个作用域：

| 作用域 | 说明 | 触发条件 | 优先级 |
|-------|------|---------|-------|
| `global` | 全局快捷键 | 应用聚焦时任何位置 | 低（编辑器内不触发） |
| `editor` | 编辑器快捷键 | Monaco 编辑器聚焦时 | 高（优先于 Monaco 内置） |

## 三、核心模块

### 3.1 shortcutManager.ts

**文件路径**：`src/utils/shortcutManager.ts`

快捷键管理核心模块，提供以下能力：

#### 类型定义

```typescript
type ShortcutScope = 'global' | 'editor';

interface ShortcutCommand {
  id: string;
  scope: ShortcutScope;
  handler: () => void;
  description?: string;
}

interface ShortcutBinding {
  commandId: string;
  keyString: string;
  keyCode: number;
}
```

#### 核心函数

**`parseShortcut(keyString: string): number`**
- 将 "Ctrl+Enter" 格式的字符串解析为 Monaco keyCode 组合值
- 支持修饰键：Ctrl/Cmd/Control/Meta、Shift、Alt/Option
- 支持普通键：字母 A-Z、数字 0-9、F1-F12、Enter、Escape、Tab、Space、Backspace、Delete、方向键、Home、End、PageUp/PageDown、`,`、`/` 等
- `Ctrl` 自动映射为跨平台的 `CtrlCmd`（Windows 上是 Ctrl，Mac 上是 Cmd）
- 解析失败返回 0

**`formatShortcut(keyCode: number): string`**
- 将 Monaco keyCode 数字反向格式化为 "Ctrl+Enter" 字符串
- 与 `parseShortcut` 互为逆操作

#### ShortcutManager 类

| 方法 | 说明 |
|-----|------|
| `registerCommand(command): () => void` | 注册命令，返回注销函数 |
| `bindShortcut(commandId, keyString)` | 绑定快捷键到命令 |
| `unbindShortcut(commandId)` | 解绑快捷键 |
| `updateShortcut(commandId, keyString)` | 更新快捷键 |
| `getShortcut(commandId)` | 获取当前快捷键字符串 |
| `getDefaultShortcut(commandId)` | 获取默认快捷键 |
| `setDefaultShortcuts(defaults)` | 批量设置默认快捷键 |
| `resetToDefault(commandId)` | 重置单个为默认 |
| `resetAllToDefault()` | 重置所有为默认 |
| `findConflicts(keyString, scope, excludeCommandId?)` | 查找冲突的命令 ID 数组 |
| `getAllBindings()` | 获取所有绑定 |
| `getCommandsByScope(scope)` | 按作用域获取命令列表 |

**单例导出**：`default shortcutManager`

### 3.2 ShortcutProvider.tsx

**文件路径**：`src/context/ShortcutProvider.tsx`

全局快捷键 Provider，负责：

1. 注册所有全局作用域的快捷键命令
2. 监听全局 `keydown` 事件
3. 与设置系统集成，动态读取/更新快捷键
4. 输入框内快捷键屏蔽逻辑

#### 键盘事件处理流程

```
keydown 事件
    │
    ▼
转换为 keyCode（keyboardEventToKeyCode）
    │
    ├── 在 Monaco 编辑器内？
    │   ├── 是 → 查找 editor 作用域绑定
    │   │       ├── 找到 → 触发 handler + preventDefault
    │   │       └── 未找到 → 不处理（让 Monaco 自己处理）
    │   └── 否 → 继续
    │
    ├── 在可编辑元素内 + 无修饰键？
    │   ├── 是 → 跳过（不干扰正常输入）
    │   └── 否 → 继续
    │
    └── 查找 global 作用域绑定
            ├── 找到 → 触发 handler + preventDefault
            └── 未找到 → 不处理
```

#### 导出

- `ShortcutProvider` - React Provider 组件
- `useShortcuts()` - Hook，返回 shortcutManager 实例

#### 集成位置

在 `AppWrapper.tsx` 的 `SettingsWrapper` 中：
```tsx
<SettingsProvider>
  <ThemeSettingsSync />
  <CacheSettingsSync />
  <AdvancedSettingsSync>
    <LocaleProvider>
      <ShortcutProvider>
        <ErrorBoundary>
          {children}
        </ErrorBoundary>
      </ShortcutProvider>
    </LocaleProvider>
  </AdvancedSettingsSync>
</SettingsProvider>
```

### 3.3 SQLEditor 集成

**文件路径**：`src/components/sql/SQLEditor.tsx`

编辑器内快捷键集成方式：

1. 组件挂载时，向 shortcutManager 注册 5 个 `editor` 作用域的命令
2. 从设置系统读取快捷键值并绑定
3. 监听设置变更，动态更新绑定
4. 组件卸载时注销命令

#### 编辑器快捷键列表

| 命令 ID | 默认快捷键 | 功能 |
|---------|-----------|------|
| `editor.executeQuery` | Ctrl+Enter | 执行当前语句 |
| `editor.executeAll` | Ctrl+Shift+Enter | 执行全部 |
| `editor.explainQuery` | Ctrl+E | 解释当前语句 |
| `editor.explainAll` | Ctrl+Shift+E | 解释全部 |
| `editor.formatSql` | Ctrl+Shift+F | 格式化 SQL |

> 注意：命令 ID 使用 `editor.` 前缀，避免与全局命令 ID 冲突

### 3.4 设置界面集成

**文件路径**：`src/components/common/SettingsModal.tsx`

为 `shortcuts` 分类的设置项提供特殊的编辑器 UI：

#### 功能特性

1. **显示模式**：展示快捷键值 + 编辑按钮
2. **编辑模式**：
   - 文本输入框输入快捷键字符串
   - 实时格式验证（绿色/红色提示）
   - 实时冲突检测（黄色警告）
   - 保存/取消按钮
   - 恢复默认按钮

#### 冲突检测

- 遍历当前 `shortcuts` 分类下的所有设置项
- 使用 `parseShortcut` 解析后比较 keyCode
- 显示冲突的设置项名称

## 五、扩展指南

### 5.1 新增快捷键（3步）

**第 1 步：后端添加默认值**

在 `settings_service.rs` 的 `default_settings()` 中添加：
```rust
("shortcuts".to_string(), "yourCommand".to_string(), "Ctrl+K".to_string(), SettingValueType::String, None, Some("你的命令".to_string())),
```

同时添加到 `implemented_settings()` 中：
```rust
set.insert(("shortcuts".to_string(), "yourCommand".to_string()));
```

**第 2 步：前端注册命令**

在合适的位置（组件挂载时或 Provider 中）注册：
```typescript
import shortcutManager from '../utils/shortcutManager';

// 在 useEffect 中注册
useEffect(() => {
  const unregister = shortcutManager.registerCommand({
    id: 'yourCommand',           // 命令 ID（全局唯一）
    scope: 'global',             // 或 'editor'
    handler: () => {
      // 快捷键触发时执行的逻辑
    },
    description: '你的命令描述',
  });
  
  // 绑定快捷键（从设置读取）
  const [shortcutValue] = useSetting('shortcuts', 'yourCommand');
  if (shortcutValue) {
    shortcutManager.bindShortcut('yourCommand', shortcutValue);
  }
  
  return () => {
    unregister();  // 组件卸载时注销
  };
}, [shortcutValue]);
```

**第 3 步：设置界面自动生效**

不需要额外修改，`SettingsModal` 会自动为 `shortcuts` 分类的所有项渲染快捷键编辑器。

## 六、设计决策

### 6.1 为什么不用 Monaco 内置的快捷键系统？

Monaco 的 `addCommand` 很好用，但有几个问题：
1. 动态更新快捷键需要使用内部 API，不稳定
2. 全局快捷键无法用 Monaco 管理
3. 统一管理更有利于扩展和维护

因此选择了：**用 shortcutManager 统一管理，通过全局 keydown 事件触发**。

### 6.2 为什么用字符串存储快捷键而不是数字？

1. 可读性好，用户能直接理解
2. 跨平台兼容（字符串中的 "Ctrl" 在 Mac 上自动映射为 Cmd）
3. 与设置系统存储格式一致

### 6.3 编辑器快捷键为什么不直接用 Monaco 的 addCommand？

为了统一管理：
- 所有快捷键都走 shortcutManager
- 统一的冲突检测
- 统一的设置界面
- 未来可以扩展为全局/编辑器两套方案灵活切换

## 七、已知限制

1. **当前只实现了 openSettings 的全局快捷键 handler**，其他全局快捷键（newFile、saveFile 等）只有空 handler，待后续功能对接
2. **部分编辑器快捷键未实现**（toggleComment、find、replace、goToLine），待后续实现
3. **不支持按键录制**，只能通过文本输入修改快捷键
4. **不支持多套快捷键方案**切换
5. **不支持导入/导出快捷键配置**
