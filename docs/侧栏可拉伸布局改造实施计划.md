# 侧栏可拉伸布局改造实施计划

> 状态：待实施
> 版本：v1.0
> 生效决策：
> - 表名显示全称（移除 text-overflow: ellipsis，靠横向滚动）
> - 右侧面板本期不预留手柄（等 schema 浏览器实现后再开）
> - 侧栏宽度：最小 180px / 默认 250px / 最大 600px

## 一、当前布局结构（改造前）

```
App.tsx  (100vh, flex column, overflow:hidden)
├── Header
└── Workspace  (flex:1, flex column, overflow:hidden)
    ├── Toolbar
    └── mainContent  (flex row, overflow:hidden)        ← 改动核心
        ├── Sidebar  (width: state.sidebar.width = 250px, 固定)
        │   ├── 导航按钮区
        │   └── sidebarContent  (flex:1, overflow:auto, 无 overflow-x)
        │       └── DatabaseExplorer / QueryHistory / TrashPanel / SnippetsPlaceholder
        ├── workspaceArea  (flex:1, flex column, overflow:hidden)
        │   ├── WorkspaceTabs
        │   └── workspaceContent  (flex:1)
        │       └── PanelManager  (column, 上下两个 panel)
        │           ├── sql_editor  (height: size%)
        │           └── results_grid (height: size%)
        └── rightPanel  (width: 0px, 占位, 未使用)
```

**当前问题**：
1. 左侧栏宽度固定 250px，用户无法调整
2. DatabaseExplorer 中长表名被 `text-overflow: ellipsis` 截断，无法看全
3. 表行 `tableName { min-width: 0 }` 让内容被压缩省略
4. `rightPanel` 是 `width: 0px` 的空壳，无实际作用

---

## 二、改造目标（仅左侧栏）

| 项 | 改造前 | 改造后 |
|----|--------|--------|
| 侧栏宽度 | 固定 250px | 拖拽右边缘可调 180~600px，双击手柄复位 250px |
| 折叠态 | 折叠后固定 48px（图标模式） | 保持不变；折叠时隐藏手柄，避免与拖拽冲突 |
| 长表名/长查询名 | 省略号截断 | 横向滚动显示全称（移除 ellipsis） |
| 宽度记忆 | 重启后总是 250px | 重启后保持用户上次设置的宽度（zustand persist + DB 同步） |
| 右侧面板 | 0px 空壳 | 本期保持不动，等 schema 浏览器实现后再启用 |
| 拖拽期间 re-render | —— | 0 次 React re-render（用原生 DOM style.width 操作，只在 mouseup 写一次 state） |

## 三、改动文件清单与改动内容

### 文件 1：src/store/workspaceStore.ts — 新增宽度操作方法

**位置**：现有的 `toggleSidebar` / `setSidebarActiveTab` 方法旁边

**改动内容**：

```
├── 新增 setSidebarWidth(width: number):
│     功能：只更新 sidebar.width，不调用 triggerAutoSave()
│     调用时机：手柄 mouseup 结束时（不是拖拽过程中每帧）
│     实现：
│       set((state) => ({
│         sidebar: { ...state.sidebar, width: Math.min(600, Math.max(180, width)) }
│       }))
│
├── 新增 resetSidebarWidth():
│     功能：复位到 250（默认值）
│     调用时机：手柄双击
│     实现：
│       set((state) => ({
│         sidebar: { ...state.sidebar, width: 250 }
│       }))
│       同步触发 triggerAutoSave() 一次
│
└── （不改动）toggleSidebar / setSidebarActiveTab
      说明：折叠态与宽度态彼此独立。
      toggleSidebar 只切换 sidebar.collapsed，不改变 sidebar.width。
      展开时读取 sidebar.width 作为实际宽度。
```

**类型检查**：`SidebarState.width` 已是 `number`，无需改类型。

**接口定义变更点**：在 `WorkspaceStore` interface 中新增两个方法签名。

**注意**：现有的 `triggerAutoSave` 会在任何 state 变化后被持久化中间件（zustand persist）自动写入 localStorage。但写入数据库 `__app_state` 的 `syncToBackend` 只在 `triggerAutoSave` 后 1500ms 触发。因此，**setSidebarWidth 不主动 triggerAutoSave**——让 zustand persist 管本地，鼠标松开后再 trigger 一次触发 DB 回写。为保险起见：resetSidebarWidth 应主动调 triggerAutoSave（因为这是显式操作，用户期望保存）。

### 文件 4：src/components/common/DatabaseExplorer.tsx — 表名显示全称

**位置**：
- `styles.tableName`（line 约 312~320）
- `styles.tableItem`
- `styles.tableRowCount`（如果有）
- `styles.systemTableBadge`

**改动内容**（关键，需逐行核对）：

```
1) tableName 样式：
   原来：
     tableName: {
       flex: 1,
       fontSize: '13px',
       color: 'var(--text-primary)',
       minWidth: 0,                    ← 删除
       overflow: 'hidden',             ← 删除
       textOverflow: 'ellipsis',       ← 删除（不再截断）
       whiteSpace: 'nowrap',
     }

   改为：
     tableName: {
       flex: '1 0 auto',   // 不压缩，跟随内容自然撑开
       fontSize: '13px',
       color: 'var(--text-primary)',
       whiteSpace: 'nowrap',
       // 不再有 min-width/overflow/text-overflow
     }

2) tableItem 样式：
   原来：
     tableItem: {
       marginBottom: '2px',
     }

   改为：
     tableItem: {
       marginBottom: '2px',
       // 关键：inline-flex + min-width:100%
       // 让单行比容器宽时推动容器出现横向滚动条
       display: 'inline-flex',
       alignItems: 'center',
       minWidth: '100%',
       boxSizing: 'border-box',
       padding: '6px 8px',
     }

3) tableHeader 样式（目前是 flex row，保持不变）：
   保持 display: flex，但确保 gap 足够，避免在窄宽度下图标和文字挤在一起。
   建议 gap: '6px'（当前是 '4px'，可调整到 6px 提升可读性）。

4) systemTableBadge / tableRowCount / 删除按钮：
   保持 flex-shrink: 0，防止这些固定宽度元素被压缩。
   当前已有 nowrap 设置，保持不变。

5) 搜索框（header 区域）：
   如果搜索框所在 header 当前是绝对 width，改为 flex 布局让它跟随容器宽度。
   具体：header 保持 flex，输入框 flex: 1，图标 flex-shrink: 0。
```

**实施风险**：
- `tableItem` 从 block 变成 inline-flex 后，`background-color hover` 可能只覆盖内容宽度（因为 inline-flex 的宽度 = 内容宽度）
- 解决：在 DatabaseExplorer 外层容器上给 `tableItem` 包裹一个 `div { width: 100% }` 让 hover 效果覆盖整行，而 inline-flex 部分只是行内布局
- 更简单的方案：**保持 tableItem 为 block/flex，不加 inline-flex；仅改 tableName 为 `min-width: 0 → min-width: auto`，并在外层 `sidebarContent` 的父级加 `overflow-x: auto`**
- 实际上方案 2 更简单且稳定：**tableName 用 `min-width: auto`（即不设置 min-width:0），让文字自然撑开；外层 `sidebarContent` 设置 `overflow-x: auto`；同时保证父容器不是 `flex:1 min-width:0` 那种会压缩内容的容器**

**最终推荐方案**（经过实际验证更可靠的写法）：

```
// DatabaseExplorer 外层容器（tablesList）
tablesList: {
  flex: 1,
  overflowX: 'auto',  ← 关键：允许横向滚动
  overflowY: 'auto',
  padding: '4px',
}

// 每个表行
tableItem: {
  marginBottom: '2px',
  display: 'flex',      ← 保持 block/flex（不 inline-flex）
  alignItems: 'center',
  minWidth: 'max-content',  ← 关键：整行不被压缩，当内容长时撑破容器 → 触发外层横向滚动
  gap: '6px',
}

// 表名
tableName: {
  flex: '1 0 auto',    ← 不压缩
  fontSize: '13px',
  color: 'var(--text-primary)',
  whiteSpace: 'nowrap',
}
```

`min-width: max-content` 是关键——它让 flex 子项的最小宽度 = 内容自然宽度，所以长表名不会被 ellipsis。外层有 `overflow-x: auto` 就会出现横向滚动。

**这个方案不需要把 display 改成 inline-flex**，更稳定，hover 背景色也能覆盖整行。

### 文件 5（新增）：src/components/workspace/SidebarResizeHandle.tsx

**组件职责**：纯事件处理的 8px 手柄，不参与 React 渲染流。

**实现代码骨架**：

```tsx
import React, { useRef, useCallback } from 'react';
import { useWorkspaceStore } from '../../store';

const MIN_WIDTH = 180;
const MAX_WIDTH = 600;
const DEFAULT_WIDTH = 250;

export const SidebarResizeHandle: React.FC = () => {
  const sidebarContainerRef = useRef<HTMLDivElement | null>(null);

  // 在挂载后找到外层 #sidebar-container
  // （因为 handle 是 #sidebar-container 的子元素，可以从 e.currentTarget.parentElement 找）
  // 这里简化：不存 ref，直接在 mouseDown 中通过 e.currentTarget.parentElement 操作

  const onMouseDown = useCallback((e: React.MouseEvent) => {
    e.preventDefault();
    e.stopPropagation();

    const handle = e.currentTarget as HTMLDivElement;
    const container = handle.parentElement as HTMLDivElement;
    if (!container) return;

    const startX = e.clientX;
    const startWidth = container.clientWidth;

    const onMouseMove = (ev: MouseEvent) => {
      const delta = ev.clientX - startX;
      const newWidth = Math.min(MAX_WIDTH, Math.max(MIN_WIDTH, startWidth + delta));
      container.style.width = `${newWidth}px`;
    };

    const onMouseUp = () => {
      window.removeEventListener('mousemove', onMouseMove);
      window.removeEventListener('mouseup', onMouseUp);

      // 最终宽度只写一次 Zustand（不触发整棵树 re-render 之前的过程）
      const finalWidth = container.clientWidth;
      const store = useWorkspaceStore.getState();
      store.setSidebarWidth(finalWidth);
      store.triggerAutoSave();

      // 移除拖拽期间样式
      document.body.style.cursor = '';
      document.body.style.userSelect = '';
      handle.style.background = '';
    };

    // 拖拽期间：禁止选中文字 + 统一光标（避免 textarea 抢事件）
    document.body.style.cursor = 'col-resize';
    document.body.style.userSelect = 'none';
    handle.style.background = 'var(--primary)';

    window.addEventListener('mousemove', onMouseMove);
    window.addEventListener('mouseup', onMouseUp);
  }, []);

  const onDoubleClick = useCallback(() => {
    // 双击复位到默认宽度
    const container = document.getElementById('sidebar-container') as HTMLDivElement | null;
    if (!container) return;
    container.style.width = `${DEFAULT_WIDTH}px`;

    const store = useWorkspaceStore.getState();
    store.setSidebarWidth(DEFAULT_WIDTH);
    store.triggerAutoSave();
  }, []);

  return (
    <div
      onMouseDown={onMouseDown}
      onDoubleClick={onDoubleClick}
      style={{
        position: 'absolute',
        top: 0,
        right: -4,          // 向右外扩 4px（视觉上在侧栏右边缘外）
        width: 8,            // 实际可点区域 8px
        height: '100%',
        cursor: 'col-resize',
        background: 'transparent',
        zIndex: 10,          // 在侧栏内容之上
        transition: 'background 0.15s',
        // 用伪元素的思路：hover 时中间显示 2px 竖线
      }}
      title="拖拽调整宽度，双击恢复默认 (250px)"
    >
      {/* 中间 2px 可见条（hover 时变亮） */}
      <div style={{
        position: 'absolute',
        top: 0,
        left: 3,
        width: 2,
        height: '100%',
        background: 'var(--border-primary)',
      }} />
    </div>
  );
};

export default SidebarResizeHandle;
```

**hover 效果**：加 `:hover` 让中间 2px 条变 `var(--primary)`——但 inline style 不能写 :hover，所以需要加一个 CSS 文件或使用一个简单的 React useState(isHovered)。

**简化 hover 方案**：用 useState + style 就够了：

```tsx
const [isHovered, setIsHovered] = useState(false);
// ...
onMouseEnter={() => setIsHovered(true)}
onMouseLeave={() => setIsHovered(false)}
// 中间条颜色根据 isHovered 切换
background: isHovered ? 'var(--primary)' : 'var(--border-primary)',
```

## 五、实施中必须遵守的架构约束

遵循 `AGENTS.md` 的分层约束：

1. **组件职责**：SidebarResizeHandle 只负责拖拽交互（鼠标事件 + 原生 DOM style.width），不读取/不渲染任何数据；DatabaseExplorer 只负责渲染列表，不做布局决策（布局由 styles 控制）。
2. **禁止跨层调用**：SidebarResizeHandle 不直接操作 Zustand state——**只在 mouseup 时通过 `useWorkspaceStore.getState()` 写入一次**，避免每帧触发订阅者的 re-render。
3. **样式规范**：所有样式写在 React 组件的 `styles` 对象中（inline style），不新增 .css 文件（与项目现有风格一致）。
4. **测试优先**：先改状态层 → 再改 UI → 最后改视觉。每一步单独验证。
5. **不动 rightPanel**：本期不启用右侧面板。
6. **类型安全**：不新增 `any`；所有改动符合 TypeScript strict 检查（或项目当前 tsc 配置）。
7. **不删除现有功能**：原有的折叠按钮、explorer/history/snippets/trash 切换，均保持原行为。

## 七、风险与回滚策略

| 风险 | 严重度 | 回滚操作 |
|------|--------|----------|
| 表行 min-width: max-content 在窄屏下表头也跟着超出 | 中 | 回退到原 `tableItem { display: flex }` + `tableName { min-width: 0; text-overflow: ellipsis }`，保留手柄可拖但回到省略号模式 |
| 折叠态展开后宽度丢失 | 中 | 在 toggleSidebar 中读取 `sidebar.width` 并设到容器上 |
| 手柄不可点击（被其他元素 z-index 覆盖） | 低 | 调手柄 z-index 到 10+，或调容器的 overflow 不遮手柄 |
| 拖拽过程中出现 React re-render 循环（不预期的 setState） | 中 | Audit：在 mouseup 之前调用 useWorkspaceStore.getState().setSidebarWidth 是直接写 state，不会触发订阅者的 re-render——但要确认没有其他地方在监听 width 变化做副作用操作；如有则改用 window resize 事件来兜底 |
| zustand persist 写入意外频繁 | 低 | 确保 setSidebarWidth 内不调用 triggerAutoSave；只在 mouseup / resetSidebarWidth 时各调一次 |
| 长中文表名 + emoji / 特殊字符导致 font 度量异常 | 低 | 先验证常见中文；发现问题时将 `tableName` 的 `whiteSpace` 设回 `normal` 但限制 max-height（最坏情况接受多行显示） |
