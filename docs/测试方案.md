## 2. 测试类型

### 2.1 前端测试

#### 2.1.1 单元测试

**技术栈**:
- `@testing-library/react` - 组件测试
- `vitest` - 测试运行器
- `@testing-library/user-event` - 用户交互模拟

**测试范围**:
- 组件渲染和 props
- 用户交互
- 状态更新
- Hooks 逻辑

**示例**:
```typescript
// src/__tests__/components/QueryEditor.test.tsx
import { describe, it, expect, vi } from 'vitest';
import { render, screen, fireEvent } from '@testing-library/react';
import { QueryEditor } from '@/components/sql/QueryEditor';

describe('QueryEditor', () => {
  it('renders SQL input', () => {
    render(<QueryEditor onExecute={vi.fn()} />);
    expect(screen.getByRole('textbox')).toBeInTheDocument();
  });

  it('calls onExecute when Ctrl+Enter pressed', async () => {
    const handleExecute = vi.fn();
    render(<QueryEditor onExecute={handleExecute} />);
    
    const textarea = screen.getByRole('textbox');
    fireEvent.change(textarea, { target: { value: 'SELECT * FROM table' } });
    fireEvent.keyDown(textarea, { key: 'Enter', ctrlKey: true });
    
    expect(handleExecute).toHaveBeenCalled();
  });
});
```

#### 2.1.3 E2E 测试

**技术栈**:
- `Playwright` - 浏览器自动化

**测试范围**:
- 用户注册/登录
- 数据导入流程
- 查询执行
- 仪表盘创建

**示例**:
```typescript
// tests/e2e/import.spec.ts
import { test, expect } from '@playwright/test';

test('import CSV and query data', async ({ page }) => {
  await page.goto('/');
  await page.click('text=开始使用');
  
  // 选择工作区
  await page.fill('[data-testid=workspace-path]', '/tmp/test-workspace');
  await page.click('button:has-text("确认")');
  
  // 导入数据
  await page.click('text=导入数据');
  await page.setInputFiles('input[type=file]', 'test-data/sales.csv');
  await page.click('button:has-text("下一步")');
  await page.click('button:has-text("开始导入")');
  
  // 验证导入成功
  await expect(page.getByText('导入成功')).toBeVisible();
  
  // 执行查询
  await page.fill('[data-testid=sql-editor]', 'SELECT * FROM sales');
  await page.click('button:has-text("执行")');
  
  // 验证结果
  await expect(page.getByText('产品A')).toBeVisible();
});
```

### 2.2 后端测试

#### 2.2.1 单元测试

**技术栈**:
- Rust 内置测试框架
- `mockall` - Mock 对象
- `tempfile` - 临时文件

**测试范围**:
- 服务层业务逻辑
- 数据访问层
- 工具函数

**示例**:
```rust
// src-tauri/src/services/query_service_test.rs
#[cfg(test)]
mod tests {
    use super::*;
    use crate::state::AppState;

    #[test]
    fn test_query_validation_success() {
        let sql = "SELECT * FROM sales";
        assert!(QueryService::validate_query(sql).is_ok());
    }

    #[test]
    fn test_query_validation_dangerous() {
        let sql = "DROP TABLE sales";
        let result = QueryService::validate_query(sql);
        assert!(matches!(result, Err(AppError::ForbiddenQuery)));
    }

    #[test]
    fn test_execute_query() {
        let state = AppState::mock();
        let result = QueryService::execute(&state, "SELECT 1", false);
        assert!(result.is_ok());
        assert_eq!(result.unwrap().row_count, 1);
    }
}
```

#### 2.2.2 集成测试

**测试范围**:
- 完整的命令调用
- 数据库交互
- 文件操作

**示例**:
```rust
// src-tauri/tests/import_integration.rs
#[tokio::test]
async fn test_import_csv_success() {
    // 1. 设置测试环境
    let temp_dir = tempfile::tempdir().unwrap();
    let state = AppState::new(temp_dir.path());
    
    // 2. 创建测试 CSV
    let test_csv = temp_dir.path().join("test.csv");
    std::fs::write(&test_csv, "id,name\n1,产品A\n2,产品B").unwrap();
    
    // 3. 执行导入
    let config = ImportConfig {
        file_path: test_csv.to_string_lossy().to_string(),
        file_type: FileType::Csv,
        table_name: "test_table".into(),
        has_header: true,
    };
    
    let result = ImportService::import(&state, config).await;
    assert!(result.is_ok());
    assert_eq!(result.unwrap().rows_imported, 2);
    
    // 4. 验证数据
    let tables = TableService::list(&state).unwrap();
    assert!(tables.iter().any(|t| t.name == "test_table"));
}
```

## 4. CI/CD 集成

### 4.1 GitHub Actions 配置

```yaml
# .github/workflows/test.yml
name: Tests

on: [push, pull_request]

jobs:
  frontend:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '20' }
      - run: npm ci
      - run: npm run build
      - run: npm run test:unit
      - run: npm run test:e2e

  backend:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - run: cargo build --verbose
      - run: cargo test --verbose -- --nocapture
      - run: cargo tarpaulin --out Xml  # 覆盖率
      
  end-to-end:
    runs-on: ubuntu-latest
    needs: [frontend, backend]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - uses: dtolnay/rust-toolchain@stable
      - run: npm ci && cargo build
      - uses: playwright install
      - run: npm run test:e2e:ci
```
