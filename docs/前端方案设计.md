## 1. 前端架构

### 1.1 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| React | 19.x | UI 框架 |
| TypeScript | 5.x | 类型系统 |
| Vite | 5.x | 构建工具 |

| AG Grid | - | 数据表格 |

| 链路 | 耗时 | 适用场景 |

| 欢迎 → 开始使用 → 快速引导 → 完成 → 主界面 | 3-5分钟 | 新用户首次使用 |

| 欢迎 → 打开设置 → 完成 → 欢迎 → 开始使用 → 主界面 | 1-5分钟 | 先设置偏好 |
