# 快速上手指南

## 1. 产品简介

LA-DUCK 是一款轻量级、高性能的本地数据库管理与可视化分析工具。基于 Rust + Tauri 构建，支持 SQLite 和 DuckDB 双引擎，提供 SQL 编辑器、数据导入、仪表盘可视化、自动化任务等完整功能。

**核心优势：**
- 🚀 极致性能：Rust 后端，启动快、占用低
- 💾 本地优先：数据存储在本地，隐私安全
- 📊 丰富图表：10+ 图表类型，拖拽式仪表盘
- ⚡ 双引擎：SQLite 适合事务，DuckDB 适合分析
- 🔄 自动化：定时任务 + Webhook 通知

## 2. 安装说明（Windows）

### 系统要求
- Windows 10 及以上版本
- 至少 2GB 可用内存
- 至少 500MB 可用磁盘空间

### 安装步骤
1. 下载最新版本的安装包（.exe 文件）
2. 双击运行安装程序
3. 按照安装向导提示完成安装
4. 安装完成后，双击桌面图标启动应用

> **注意：** 首次启动可能需要几秒时间初始化数据库，请耐心等待。

## 3. 快速开始三步曲

### 第一步：创建数据库连接

1. 启动应用后，进入「项目管理」
2. 点击「新建项目」，输入项目名称
3. 选择数据库类型（SQLite 或 DuckDB）
4. 指定数据库文件路径，点击「创建」
5. 项目创建成功后，点击进入项目

### 第二步：执行 SQL 查询

1. 在左侧导航栏点击「SQL 编辑器」
2. 在编辑器中输入 SQL 语句，例如：
   ```sql
   -- 创建示例表
   CREATE TABLE users (
       id INTEGER PRIMARY KEY,
       name TEXT NOT NULL,
       age INTEGER,
       email TEXT
   );
   
   -- 插入示例数据
   INSERT INTO users (name, age, email) VALUES
       ('张三', 28, 'zhangsan@example.com'),
       ('李四', 35, 'lisi@example.com'),
       ('王五', 22, 'wangwu@example.com');
   
   -- 查询数据
   SELECT * FROM users;
   ```
3. 点击「执行」按钮或按 `Ctrl+Enter` 运行
4. 下方结果面板将显示查询结果
5. 查询记录会自动保存到「查询历史」中

### 第三步：创建仪表盘

1. 在左侧导航栏点击「仪表盘」
2. 点击「新建仪表盘」，输入名称
3. 点击「添加图表」，选择图表类型（柱状图、折线图、饼图等）
4. 配置图表数据源：选择数据表和字段
5. 拖拽调整图表大小和位置
6. 点击「保存」完成仪表盘创建

## 5. 常见问题 FAQ

### Q: 数据存储在哪里？
A: 所有数据都存储在本地，默认位置为用户目录下的 `.la-duck` 文件夹。你可以在设置中修改存储路径。

### Q: 支持哪些数据库？
A: 当前版本支持 SQLite 和 DuckDB。SQLite 适合事务型操作，DuckDB 适合大数据量分析查询。

### Q: 如何导出查询结果？
A: 在查询结果面板右上角点击「导出」按钮，选择 CSV 或 Excel 格式即可。

### Q: 大文件导入很慢怎么办？
A: 建议：
- 使用 DuckDB 引擎，它对大数据量导入有优化
- 分批导入，每次不超过 10 万行
- 关闭其他占用资源的程序

### Q: 如何备份数据？
A: 直接复制数据库文件即可。SQLite 是单文件数据库，DuckDB 也是文件级存储。

### Q: 忘记密码怎么办？
A: 本地版本无需密码登录。如果设置了应用锁且忘记密码，需要删除配置文件重置（会丢失设置，但不会丢失数据库文件）。

### Q: 可以同时打开多个项目吗？
A: 可以。你可以创建多个项目，每个项目对应独立的数据库文件，数据完全隔离。
