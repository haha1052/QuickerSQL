### P2-2 | 依赖版本过时（4 项）⚠️ 暂不升级

- **位置**: `src-tauri/Cargo.toml`、`package.json`
- **问题描述**:
  | 依赖 | 当前版本 | 问题 | 建议版本 |
  |------|---------|------|---------|
  | `rusqlite` | `=0.32.1` | 严重过时（0.32 不再维护） | `^0.35` |
  | `duckdb` | `1.10502.0` | 版本号格式异常（不符合 semver） | 核查官方最新格式 |
  | `thiserror` | `=1.0.69` | 1.x 进入维护模式 | `^2.0` |
  | 14 个 Rust 依赖 | `=version` 精确锁定 | 安全补丁无法快速应用 | 改为 `^version` + Cargo.lock |
- **影响**: 安全补丁无法应用，潜在兼容性问题。
- **当前状态**: **用户决策暂不升级**（2026-08-20）。原因：rusqlite 0.32→0.35 涉及 API 变更，需谨慎测试；当前版本运行稳定，无紧急安全风险。后续如需处理，单独发起 spec。

### P2-3 | 前端 SQL 关键字检测规则误报（1744 条 → 0 条）✅ 已修复（2026-08-20）

- **修复版本**: v26.2
- **修复内容**: 修订前端 SQL 检测规则（v26.2 修订版），采用 case-sensitive 匹配 + 排除 SQL 客户端工具类目录 + safe_sql 白名单机制
- **修订要点**:
  1. case-sensitive 匹配：原 `-CaseSensitive:$false` 会匹配 `<select>` HTML 元素、`selection` 变量等非 SQL 关键字
  2. 排除 SQL 客户端工具类目录：`src/components/sql/`、`src/utils/sql*`、`src/utils/resultCopy`、`src/context/LocaleContext.tsx`
  3. 排除测试文件：`src/__tests__/`、`*.test.ts`、`*.test.tsx`
  4. safe_sql 白名单：对剩余合法用例（SQL 客户端工具生成的 SQL 模板）添加 `// safe_sql:` 注释标记
- **同步修订的规则文件**: `.trae/rules/security.md`、`.trae/rules/CLAUDE.local.md` §2.2、`.trae/rules/mcp.md` §十二
- **验证结果**: 误报从 1744 条降至 0 条 ✅
- **详见**: [历史技术债.md](./历史技术债.md) §八

- **问题描述**: 三套版本号各自独立演进，容易造成混淆。
