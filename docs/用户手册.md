# QuickerSQL 用户手册

> 本手册面向 QuickerSQL 的初级到中级用户，帮助您快速上手并掌握核心功能。

---

## 第 1 章：快速开始

### 1.1 安装说明

QuickerSQL 是一款基于 Tauri + React + Rust 的轻量级数据库管理工具，支持 SQLite 和 DuckDB。

**系统要求：**

- Windows 10/11（64位）
- 至少 4GB 内存
- 至少 200MB 磁盘空间

**下载安装：**

1. 从 GitHub Releases 页面下载最新版本的安装包（`.exe` 或 `.msi`）
2. 双击安装包，按照向导完成安装
3. 安装完成后，在开始菜单或桌面找到 QuickerSQL 图标

**首次启动：**

首次启动时，QuickerSQL 会自动创建一个默认的 SQLite 数据库文件 `quick_sql.db`，用于存储应用配置和查询历史。

### 1.2 启动应用

**启动方式：**

- 方式一：双击桌面快捷方式
- 方式二：从开始菜单搜索 "QuickerSQL" 并点击
- 方式三：如果使用开发版本，在项目目录下运行 `npm run tauri dev`

**初始界面介绍：**

启动后，您将看到 QuickerSQL 的主界面，主要包含以下区域：

### 1.3 创建第一个数据库连接

QuickerSQL 默认使用内置的 SQLite 数据库，无需额外配置即可开始使用。

**连接管理：**

1. 点击顶部栏右侧的「设置」按钮（齿轮图标）
2. 在设置面板中，选择「数据库」分类
3. 您可以看到当前连接的数据库信息

**创建新的数据库连接：**

1. 在设置面板的「数据库」分类中
2. 点击「新建连接」按钮
3. 选择数据库类型（SQLite 或 DuckDB）
4. SQLite：选择 `.db` 文件或创建新数据库
5. DuckDB：选择 `.duckdb` 文件或创建新数据库
6. 点击「测试连接」验证连接是否成功
7. 点击「保存」完成配置

### 1.4 基本操作流程

**新建标签页：**

1. 点击标签栏右侧的 `+` 按钮
2. 或使用快捷键 `Ctrl+T`
3. 新标签页将创建空白工作区

**编写 SQL：**

1. 在 SQL 编辑器中输入 SQL 语句
2. 支持语法高亮和自动补全
3. 可以同时编写多条 SQL 语句（用分号分隔）

**执行查询：**

1. 方式一：点击编辑器右上角的「执行」按钮
2. 方式二：使用快捷键 `Ctrl+Enter`
3. 方式三：选中部分 SQL 后执行（只执行选中部分）

**查看结果：**

- 查询结果将显示在编辑器下方的表格中
- 支持分页浏览（默认每页 1000 行）
- 可以导出结果为 CSV 或 Excel 格式

## 第 2 章：数据查询

### 2.1 连接管理

**查看当前连接：**

- 顶部栏左侧显示当前连接的数据库类型和名称
- 绿色圆点表示连接正常
- 红色圆点表示连接断开

**切换数据库：**

1. 点击连接状态区域
2. 从下拉列表中选择其他已保存的连接
3. 或点击「管理连接」进入连接管理

**连接池：**

QuickerSQL 支持同时维护多个数据库连接，您可以在不同标签页中连接不同的数据库。

### 2.2 SQL 编辑器

**主要功能：**

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 执行查询 | `Ctrl+Enter` | 执行当前光标所在或选中的 SQL |
| 格式化 SQL | `Ctrl+Shift+F` | 自动格式化 SQL 语句 |
| 注释/取消注释 | `Ctrl+/` | 切换当前行的注释状态 |
| 撤销/重做 | `Ctrl+Z` / `Ctrl+Y` | 撤销或重做编辑 |
| 全选 | `Ctrl+A` | 选中编辑器所有内容 |
| 保存到历史 | `Ctrl+S` | 将当前 SQL 保存到查询历史 |

**语法高亮：**

编辑器支持 SQL 关键字、字符串、数字、注释等不同元素的语法高亮，帮助您更清晰地阅读和编写 SQL。

**自动补全：**

- 输入部分关键字时，自动显示候选列表
- 支持表名、列名的补全
- 按 `Tab` 或 `Enter` 确认补全

### 2.3 查询执行

**执行方式：**

- **单条执行**：光标在某条 SQL 上时，只执行该条
- **选中执行**：选中文本时，只执行选中部分
- **全部执行**：无选中时，执行编辑器所有 SQL

**执行状态：**

- 执行中：显示旋转的加载图标
- 成功：显示绿色勾号和执行时间
- 失败：显示红色叉号和错误信息

**执行结果面板：**

- 包含「结果」「消息」「执行计划」三个标签页
- 「结果」：显示查询返回的数据表格
- 「消息」：显示受影响的行数、警告信息等
- 「执行计划」：显示 SQL 的执行计划（EXPLAIN）

### 2.4 结果展示

**表格功能：**

| 功能 | 说明 |
|------|------|
| 列排序 | 点击列标题可升序/降序排序 |
| 列宽调整 | 拖动列标题边缘调整列宽 |
| 行数显示 | 底部显示总行数和当前页信息 |
| 分页导航 | 支持首页/上一页/下一页/末页 |

**导出功能：**

1. 点击结果表格右上角的「导出」按钮
2. 选择导出格式（CSV / Excel）
3. 选择导出范围（当前页 / 全部）
4. 选择保存路径
5. 点击「导出」完成

## 第 3 章：仪表盘

### 3.1 创建图表

**进入仪表盘：**

1. 点击侧边栏的「仪表盘」按钮
2. 或使用快捷键 `Ctrl+D`
3. 进入仪表盘管理页面

**新建图表：**

1. 点击「新建图表」按钮
2. 在弹出的对话框中：
   - 输入图表名称
   - 选择数据源（SQL 查询或已保存的查询）
   - 选择图表类型（柱状图、折线图、饼图等）
   - 配置 X 轴和 Y 轴字段
3. 点击「保存」创建图表

**图表类型：**

| 类型 | 适用场景 |
|------|----------|
| 柱状图 | 展示分类数据的对比 |
| 折线图 | 展示数据随时间变化的趋势 |
| 饼图 | 展示各部分占总体的比例 |
| 散点图 | 展示两个变量之间的相关性 |
| 面积图 | 展示累积数据的变化趋势 |

### 3.2 布局调整

**添加图表到仪表盘：**

1. 创建或选择一个仪表盘
2. 点击「添加图表」按钮
3. 从图表库中选择要添加的图表
4. 图表将添加到仪表盘的画布上

**调整布局：**

- **移动**：拖动图表到新位置
- **调整大小**：拖动图表边缘调整宽高
- **删除**：选中图表后按 `Delete` 键或点击删除按钮

**布局工具：**

| 工具 | 功能 |
|------|------|
| 网格吸附 | 启用后图表自动对齐到网格 |
| 缩放 | 调整画布显示比例 |
| 全屏 | 进入全屏编辑模式 |

### 3.3 保存与加载

**保存仪表盘：**

1. 点击工具栏的「保存」按钮
2. 或使用快捷键 `Ctrl+S`
3. 输入仪表盘名称（首次保存）
4. 仪表盘自动保存到本地数据库

**加载仪表盘：**

1. 在仪表盘列表页面
2. 点击要打开的仪表盘
3. 或在侧边栏的「仪表盘」菜单中选择

**仪表盘列表：**

- 显示所有已保存的仪表盘
- 支持搜索和筛选
- 支持设为默认仪表盘

## 第 4 章：自动化任务

### 4.1 创建任务

**进入任务中心：**

1. 点击侧边栏的「任务中心」按钮
2. 或使用快捷键 `Ctrl+T`
3. 进入任务管理页面

**新建任务：**

1. 点击「新建任务」按钮
2. 在任务配置页面填写：
   - **任务名称**：必填，用于标识任务
   - **任务类型**：查询 / 导出 / 导入
   - **执行内容**：SQL 语句或文件路径
   - **描述**：可选的任务说明

### 4.2 调度配置

**调度模式：**

| 模式 | 说明 |
|------|------|
| 手动执行 | 需要手动触发运行 |
| 定时执行 | 按 cron 表达式定时运行 |
| 间隔执行 | 按固定时间间隔循环运行 |

**配置定时任务：**

1. 选择「定时执行」模式
2. 输入 cron 表达式（如 `0 0 * * *` 表示每天午夜）
3. 或使用可视化配置器选择执行时间
4. 开启「启用」开关激活任务

**常用 cron 表达式：**

| 表达式 | 含义 |
|--------|------|
| `0 * * * *` | 每小时整点执行 |
| `0 0 * * *` | 每天午夜执行 |
| `0 0 * * 0` | 每周日执行 |
| `0 0 1 * *` | 每月1日执行 |
| `*/5 * * * *` | 每5分钟执行 |

### 4.3 运行监控

**查看运行历史：**

1. 在任务列表中点击某个任务
2. 进入任务详情页面
3. 切换到「运行记录」标签
4. 查看该任务的历史执行记录

**运行记录信息：**

| 字段 | 说明 |
|------|------|
| 状态 | 成功 / 失败 / 运行中 |
| 开始时间 | 任务开始执行的时间 |
| 结束时间 | 任务完成的时间 |
| 执行时长 | 任务运行耗时 |
| 输出 | 任务执行结果或错误信息 |

**手动运行任务：**

1. 在任务列表中找到目标任务
2. 点击「立即运行」按钮
3. 任务将立即执行（不受调度时间限制）

**任务状态：**

- **禁用**：任务暂停，不会自动执行
- **启用**：任务正常运行，按调度计划执行
- **运行中**：任务正在执行中

### 常见问题

**Q: 查询执行很慢怎么办？**

A: 可以尝试以下方法：
1. 检查是否有合适的索引
2. 使用 EXPLAIN 查看执行计划
3. 添加查询条件限制返回行数
4. 启用查询结果分页

**Q: 如何备份数据库？**

A: 关闭应用后，直接复制数据库文件（`.db` 或 `.duckdb`）到安全位置即可。

**Q: 误删了数据怎么恢复？**

A: QuickerSQL 有回收站功能，删除的表会先移到回收站，可在回收站中恢复。
