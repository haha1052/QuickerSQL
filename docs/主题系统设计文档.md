# QuickerSQL 主题系统设计文档

## 概述

QuickerSQL 应用支持三种主题模式：
- 🌞 **浅色模式 (Light Mode)** - 清爽明亮的日间视觉体验
- 🌙 **深色模式 (Dark Mode)** - 护眼舒适的夜间视觉体验
- 🖥️ **跟随系统 (System Default)** - 自动跟随操作系统的主题偏好

## 设计原则

1. **一致性** - 所有组件在不同主题下保持相同的布局结构和交互方式
2. **可读性** - 确保文本与背景的对比度符合 WCAG AA 标准
3. **柔和过渡** - 主题切换时有 0.3s 的平滑动画
4. **系统适配** - 支持 `prefers-color-scheme` 媒体查询实现跟随系统

  background: var(--bg-secondary);
  border: 1px solid var(--border-primary);
  border-radius: 10px;
  box-shadow: var(--shadow);

  box-shadow: var(--shadow-hover);

## 实现架构

### 1. CSS 变量定义 (`src/styles/theme.css`)
- 通过 `:root` 定义默认（浅色）主题变量
- 通过 `[data-theme="dark"]` 定义深色主题变量
- 使用 `prefers-color-scheme: dark` 实现跟随系统

### 2. 主题状态管理 (`src/context/ThemeContext.tsx`)
- 使用 `ThemeProvider` 包裹整个应用
- `useTheme` hook 获取当前主题和切换方法
- 支持 `light`/`dark`/`system` 三种模式
- 自动保存用户偏好到 `localStorage`

### 3. 与设置系统集成
- 主题设置项 key: `appearance-theme`
- 设置变更自动同步到主题系统
- 主题切换实时响应，无需重启

### 4. 组件主题化
- 所有组件使用 CSS 变量定义样式
- 不硬编码颜色值
- 支持平滑的主题切换动画

## 主题切换流程

```
用户修改设置
  ↓
SettingsStore 更新
  ↓
ThemeContext 监听并更新 data-theme 属性
  ↓
CSS 变量自动更新
  ↓
所有组件样式同步变化
  ↓
0.3s 平滑动画完成
```

## 技术要点

### 平滑过渡
```css
* {
  transition: background-color 0.3s ease, 
              border-color 0.3s ease, 
              color 0.3s ease, 
              box-shadow 0.3s ease;
}
```

### 系统主题检测
```javascript
const isSystemDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
```

### 系统主题变更监听
```javascript
window.matchMedia('(prefers-color-scheme: dark)').addEventListener('change', (e) => {
  if (currentTheme === 'system') {
    applyTheme(e.matches ? 'dark' : 'light');
  }
});
```
