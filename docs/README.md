## 🚀 快速开始

### 开发环境搭建

```bash
# 1. 克隆项目
git clone https://github.com/quickersql/quickersql.git
cd quickersql

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run tauri dev

# 4. 运行测试
npm run test

# 5. 代码检查
npm run lint
npm run typecheck
```

### 构建发布版本

```bash
# 构建所有平台
npm run tauri build

# 仅构建前端
npm run build

# 仅构建后端
cd src-tauri && cargo build --release
```

## ❓ 常见问题

### Q: 应该先读哪份文档？

**A:** 取决于你的角色和目的：
- **项目经理/决策者**：先读 README.md 和 实施计划与里程碑.md
- **开发者**：先读 README.md + 技术规范与开发方案_阶段1-2.md，然后深入专项文档
- **评估者**：先读 README.md + 技术规范与开发方案_阶段1-2.md

### Q: 文档之间有什么关联？

**A:** 
- README.md 是入口文档，提供导航
- 技术规范与开发方案_阶段1-2.md 是综合概览，索引到专项文档
- 专项文档之间相互引用
- 实施计划与里程碑.md 整合所有专项文档作为实施依据

### Q: 如何报告文档问题？

**A:** 请通过以下方式报告：
1. 在 GitHub 仓库创建 Issue
2. 标签选择 `documentation`
3. 详细描述问题和建议
