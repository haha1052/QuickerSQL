```

  │   ├── 图表库按钮 (ChartLibraryPanel)               │
```

### 1.2 三层数据结构

| 层级 | 类型 | 职责 | 关键字段 |
|------|------|------|---------|
| **图表定义** | `SavedChart` | 图表的配置模板（SQL、坐标轴、类型、ECharts config） | `sql`, `config`, `chartType`, `xAxis`, `yAxis` |
| **仪表盘** | `Dashboard` | 仪表盘容器（名称、筛选器、`layout: DashboardItem[]`） | `layout[]`, `filters[]` |
| **仪表盘项** | `DashboardItem` | **每个图表在仪表盘中的放置实例**（位置、大小） | `x`, `y`, `width`, `height`, `chartId`, `configOverrides` |

### 1.3 CSS Grid 布局规则

- **画布**: `display: grid; gridTemplateColumns: repeat(12, 1fr); gridAutoRows: 80px;`
- **单个图表项**:
  - `gridColumn: ${x+1} / span ${width}` — 从第 x+1 列开始，占 width 列
  - `gridRow: ${y+1} / span ${height}` — 从第 y+1 行开始，占 height 行
  - 行高 80px，所以 height=4 实际高度 = 320px

## 二、当前缺陷清单（按严重度排序）

### 🔴 缺陷 1：新图表位置硬编码在 (0,0)，覆盖原有图表

**位置**: `src/components/dashboard/AddChartModal.tsx:38`

```typescript
await addChartToDashboard(dashboardId, selectedChartId, { x: 0, y: 0, width: 6, height: 4 });
                                                              ^^^^^^  ^^^^^^  ^^^^^^^^^^  ^^^^^^^^^^
                                                              全部固定为默认值！
```

**问题**: 无论添加多少张图表，都固定放在同一位置 (0,0) 宽 6 高 4。由于 CSS Grid 在相同位置重叠时，后添加的图表**覆盖**在之前的图表之上，所以视觉上只看到最后添加的一张，之前的被覆盖在下方。

### 🔴 缺陷 2：编辑模式无真正的拖拽 / 缩放功能

**位置**: `src/components/dashboard/DashboardItem.tsx`（仅样式变化）

```typescript
itemEditing: {
  border: '2px solid var(--primary)',
  cursor: 'move',       // ⚠️ 鼠标样式是"可移动"，但没有实际的拖拽逻辑！
},
```

**问题**:
- 编辑模式下，图表边框变蓝、光标显示为 "move" 手势 —— **但没有真正的拖拽事件监听**
- **没有 resize handles（缩放手柄）**
- **位置/大小变化后不持久化**

### 🟠 缺陷 3："保存布局" 按钮实际不保存任何东西

**位置**: `src/components/dashboard/DashboardPage.tsx:83`

```typescript
onToggleEdit={() => setIsEditing(v => !v)}
```

问题:
- "📝 编辑" → 进入编辑模式（仅 CSS 边框变化）
- "✅ 保存布局" → 退出编辑模式（**没有任何后端调用**）
- 正确应该是：`saveLayout()` → 遍历当前 `dashboard.layout`，逐个 `updateDashboardItem` 持久化 x/y/width/height

### 🟡 缺陷 4：添加图表时缺少自动定位算法

缺少类似这样的自动定位逻辑：
```
方案 A —— 顺序排列：
   新图表 y = 最后一个图表的 y + height（追加到下方）

方案 B —— 紧凑排列（Bin Packing）：
   扫描所有空白位置，找第一个能放下新图表的位置

方案 C —— 默认右对齐：
   如果已有 1 个图表在 (0,0,6,4)，新图表从 (6,0,6,4) 开始
```

### 🟡 缺陷 5：图表渲染时如果 sql 字段为空，应给出更明确的提示

当前：图表如果缺少 `sql`，会尝试回退到 `queryId`，如果也失败，就显示错误信息。

**可以改进**：告诉用户"该图表缺少 SQL，请在图表编辑面板中补全 SQL"。

### 🟢 缺陷 6：SaveChartModal 中保存图表到仪表盘时，也使用固定位置

**位置**: `src/components/chart/SaveChartModal.tsx:111`


### T1：修复添加图表位置（自动定位算法）

**目标**: 新增图表不再重叠在 (0,0)

**实现方案**:

1. 新增工具函数 `src/utils/gridLayout.ts`：

```typescript
/**
 * 计算新图表在仪表盘画布中的自动放置位置
 * 策略：从左到右、从上到下依次排列，类似流式布局
 * 画布为 12 列网格，每个图表默认宽 6 列、高 4 行（320px）
 */
export function calculateNextPosition(
  items: Array<{ x: number; y: number; width: number; height: number }>,
  newItemSize: { width: number; height: number } = { width: 6, height: 4 }
): { x: number; y: number; width: number; height: number } {
  // 如果没有现有 items，新图表放在原点
  if (items.length === 0) {
    return { x: 0, y: 0, width: newItemSize.width, height: newItemSize.height };
  }

  // 找出当前布局中最右下的位置
  let maxRight = 0;
  let maxBottom = 0;
  for (const item of items) {
    maxRight = Math.max(maxRight, item.x + item.width);
    maxBottom = Math.max(maxBottom, item.y + item.height);
  }

  // 策略：尝试放在当前行右侧
  // 从最后一行的起始位置开始向右查找空白
  const lastItems = [...items].sort((a, b) => (b.y + b.height) - (a.y + a.height));
  const bottomY = lastItems[0]?.y ?? 0;
  const bottomRowItems = items.filter(item => item.y < bottomY + 1 && item.y + item.height > bottomY);

  // 计算当前行最右位置
  let currentRowRight = 0;
  for (const item of bottomRowItems) {
    currentRowRight = Math.max(currentRowRight, item.x + item.width);
  }

  // 如果当前行右侧还有空间（12 - currentRowRight >= newItemSize.width）
  if (12 - currentRowRight >= newItemSize.width) {
    // 放在当前行右侧
    return {
      x: currentRowRight,
      y: bottomY,
      width: newItemSize.width,
      height: newItemSize.height,
    };
  }

  // 否则放在下一行的开头
  return {
    x: 0,
    y: maxBottom,
    width: newItemSize.width,
    height: newItemSize.height,
  };
}
```

```typescript
// 原来的 addChartToDashboard 调用改为：
```

### T2："保存布局" 按钮真正保存

**目标**: 点击"✅ 保存布局"时，将当前所有图表的 x/y/width/height 写回数据库

**实现方案**:

1. 在 `dashboardStore.ts` 中新增 action:

```typescript
saveLayout: async (dashboardId: string, items: Array<{ id: string; x: number; y: number; width: number; height: number }>) => {
  set({ loading: true, error: null });
  try {
    // 逐个更新每个 item 的位置
    for (const item of items) {
      await tauriService.updateDashboardItem(item.id, {
        x: item.x,
        y: item.y,
        width: item.width,
        height: item.height,
      });
    }
    // 重新加载仪表盘
    const dashResponse = await tauriService.getDashboard(dashboardId);
    if (dashResponse.success && dashResponse.data) {
      set((state) => ({
        dashboards: state.dashboards.map((d) =>
          d.id === dashboardId ? dashResponse.data! : d
        ),
        loading: false,
      }));
    } else {
      set({ loading: false });
    }
  } catch (e) {
    set({ error: String(e), loading: false });
  }
},
```

### T3：编辑模式下的拖拽移动

**目标**: 编辑模式下可以用鼠标拖拽图表改变位置

**实现方案（在 DashboardItem.tsx 中实现）**:

```typescript
// DashboardItem 组件中的状态
const [dragging, setDragging] = useState(false);
const [dragOffset, setDragOffset] = useState({ x: 0, y: 0 });

// 新增拖拽逻辑
const handleMouseDown = (e: React.MouseEvent) => {
  if (!isEditing) return;
  e.stopPropagation();
  setDragging(true);

  const canvasEl = document.querySelector('[data-dashboard-canvas]');
  if (!canvasEl) return;

  const canvasRect = canvasEl.getBoundingClientRect();
  const colWidth = canvasRect.width / 12;
  const rowHeight = 80;

  // 记录起始鼠标相对画布的网格位置
  const startMouseX = e.clientX - canvasRect.left;
  const startMouseY = e.clientY - canvasRect.top;
  const startGridX = Math.floor(startMouseX / colWidth);
  const startGridY = Math.floor(startMouseY / rowHeight);

  const startItemX = item.x;
  const startItemY = item.y;

  const handleMouseMove = (moveEvent: MouseEvent) => {
    const mouseX = moveEvent.clientX - canvasRect.left;
    const mouseY = moveEvent.clientY - canvasRect.top;
    const gridX = Math.round(mouseX / colWidth - 0.5);
    const gridY = Math.round(mouseY / rowHeight - 0.5);

    const deltaX = gridX - startGridX;
    const deltaY = gridY - startGridY;

    // 计算新位置（限制在画布范围内：0 ≤ x ≤ 12-width, 0 ≤ y）
    let newX = Math.max(0, Math.min(12 - item.width, startItemX + deltaX));
    let newY = Math.max(0, startItemY + deltaY);

    // 更新 store 中该 item 的位置（本地临时状态）
    const { updateDashboardItem } = useDashboardStore.getState();
    // ⚠️ 注意：这里应该先更新一个"临时布局" state，等保存时再统一写入后端
  };

  const handleMouseUp = () => {
    setDragging(false);
    document.removeEventListener('mousemove', handleMouseMove);
    document.removeEventListener('mouseup', handleMouseUp);
  };

  document.addEventListener('mousemove', handleMouseMove);
  document.addEventListener('mouseup', handleMouseUp);
};
```

**优化点**：为避免频繁写后端，建议在 `dashboardStore.ts` 中新增一个 `tempLayout: DashboardItem[]` 状态，编辑模式下只修改 `tempLayout`，保存时才写回 `dashboard.layout`。
