## 一、如何打开设置

### 方式一：快捷键
- **快捷键**：按 `Ctrl + ,`（逗号键）
- **适用场景：快速打开设置窗口

### 方式二：菜单
- 点击界面右上角的设置图标（齿轮形状）
- 或从主菜单中选择「设置」

### 设置界面说明：
- 左侧：分类导航栏，14 个分类可切换
- 右侧：当前分类的所有设置项
- 修改后**自动保存**，立即生效

## 十、缓存设置 (Cache)

> 💾 共 4 项设置，查询缓存加速重复查询

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| **启用查询缓存** | true | 缓存查询结果，相同查询直接返回缓存 |
| **缓存大小** | 100 | 缓存占用的最大空间，单位 MB |
| **缓存过期时间** | 30 | 缓存条目保留时间，单位分钟 |
| **缓存策略** | lru | 缓存淘汰策略<br>可选：lru（最近最少使用）、none（不缓存） |

**工作原理：
- 当您执行一条 SELECT 查询时，结果会被缓存起来
- 如果下一次执行相同的 SQL，直接从缓存返回，速度极快
- 当数据有写操作（INSERT/UPDATE/DELETE）时，缓存自动失效

**缓存策略说明：
- `lru`（推荐）：保留最近使用的缓存，满了淘汰最久没用的
- `none`：完全关闭缓存，每次都直接查询

> 💡 **什么时候用 none 适合频繁查询相同数据，缓存大幅提升速度。如果数据实时性要求极高，可以调小过期时间或关闭缓存。

## 十六、常见问题与使用技巧

### Q1：修改设置后多久生效？
**A：** 绝大多数设置修改后**立即生效**，不需要重启应用。

### Q2：设置保存在哪里？
**A：** 设置保存在本地数据库中，路径在用户数据目录下。卸载应用不会丢失设置。

### Q3：如何恢复默认设置？
**A：** 目前没有一键恢复默认功能，可以手动改回默认值（参考上面各表中的默认值）。

### Q4：推荐新手推荐设置
**Q5：缓存有什么用？
**A：** 对于重复查询大幅提升查询速度。比如同一条 SQL 第一次执行需要 5 秒，第二次从缓存只要几毫秒。

### Q6：审计日志有什么用？
**A：** 记录所有操作记录谁什么时候做了什么操作，用于安全审计和问题排查。

### Q7：开发者模式要不要开？
**A：** 普通用户不需要开。遇到问题需要调试时再打开可以看到更多错误信息。

### Q8：密码忘了密码保护密码
**A：** 密码保存在本地，无法找回。如果忘记了，只能清除应用数据重置。
