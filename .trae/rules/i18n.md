> 优先级：高（与 coding.md 同级）。
> 适用：所有前端 `.ts/.tsx` 文件中"用户可见文字"的国际化约束。

## 一、核心原则（零容忍）

### 1.1 单一翻译源

- ✅ **所有用户可见的前端文字**必须通过 `useLocale().t(key)` 或 `t(key, vars)` 翻译
- ✅ 翻译键统一维护在 [LocaleContext.tsx](file:///e:/LA_DUCK/la-duck/src/context/LocaleContext.tsx) 的 `zhCNTranslations` 与 `enUSTranslations` 两个对象中，键名一一对应
- ❌ 禁止在 `.ts/.tsx` 中硬编码中文/英文 UI 文案（含按钮文字、placeholder、toast 提示、错误信息、菜单 label、表格表头、对话框标题等）
- ❌ 禁止用 `// @ts-ignore` 绕过 i18n 检测

### 1.2 "用户可见文字"判定

| 类型 | 是否必须 i18n | 示例 |
|------|--------------|------|
| 按钮 / 链接文字 | ✅ 必须 | `<button>保存</button>` → `<button>{t('common.save')}</button>` |
| placeholder | ✅ 必须 | `placeholder="请输入"` → `placeholder={t('common.inputPlaceholder')}` |
| toast / setMessage 文案 | ✅ 必须 | `setMessage('操作失败', 'error')` → `setMessage({ key: 'common.operationFailed', vars })` 或 `setMessage('common.operationFailed', 'error')` |
| 错误提示（throw new Error） | ✅ 必须 | `throw new Error('加载失败')` → `throw new Error(t('error.task.load_failed'))` 或抛 i18n key 由调用方翻译 |
| 菜单 / 选项 label | ✅ 必须 | `{ label: '柱状图' }` → `{ label: t('chart.bar') }` |
| 表格表头 / 列名 | ✅ 必须 | — |
| 对话框标题 / 确认文案 | ✅ 必须 | `confirm('确定删除？')` → `confirm(t('common.confirmDelete'))` |
| title / tooltip | ✅ 必须 | `title="刷新"` → `title={t('common.refresh')}` |
| **console.log/warn/error** | ❌ 不需要 | 开发日志，不展示给最终用户 |
| **SQL 关键字** | ❌ 不需要 | `SELECT/INSERT` 等是 SQL 语法 |
| **代码注释** | ❌ 不需要 | `// 加载表列表` |
| **测试数据**（`__tests__/`、`*.test.ts`） | ❌ 不需要 | 测试固件 |
| **翻译表本身**（LocaleContext.tsx） | ❌ 不需要 | 它就是翻译源 |

## 二、翻译键命名规范

### 2.1 命名空间约定

翻译键采用扁平的 `'namespace.key'` 格式（非嵌套对象），命名空间划分：

| 命名空间 | 用途 | 示例 |
|---------|------|------|
| `common.*` | 通用按钮/状态文案 | `common.save`、`common.cancel`、`common.loading` |
| `header.*` | 顶部导航 | `header.project`、`header.sqlQuery` |
| `toolbar.*` | 工具栏 | `toolbar.runQuery`、`toolbar.exportResult` |
| `query.*` | SQL 查询页 | `query.executionTime`、`query.parameterInput` |
| `grid.*` | 结果网格 | `grid.copySelectedRows`、`grid.copyAsCsv` |
| `chart.*` | 图表 | `chart.bar`、`chart.renderFailed` |
| `dashboard.*` | 仪表盘 | `dashboard.newDashboard`、`dashboard.saveLayout` |
| `settings.*` | 设置 | `settings.language`、`settings.theme` |
| `import.*` | 数据导入 | `import.fileTooLarge`、`import.importFailed` |
| `automation.*` | 自动化任务 | `automation.taskType.sql`、`automation.cron.everyMinute` |
| `error.*` | 错误信息（throw/setError） | `error.task.load_failed`、`error.dashboard.create_failed` |
| `toast.*` | toast 通知 | `toast.duckdbInitSuccess`、`toast.startupComplete` |
| `snippets.*` | SQL 片段 | `snippets.loadFailed`、`snippets.deleteConfirm` |
| `profile.*` | 探查 | `profile.selectTableFirst`、`profile.analyzing` |

### 2.2 键名规则

- ✅ 键名用 `camelCase`：`loadFailed`、`copySelectedRows`
- ✅ 命名空间用 `lowercase`：`error`、`toast`
- ✅ 变量插值用 `{varName}`：`'已同步 {count} 个表（耗时 {ms}ms）'`
- ❌ 禁止键名含中文、空格、特殊字符
- ❌ 禁止同一概念用两个键（如 `common.save` 和 `button.save`）

### 2.3 新增翻译键的强制流程

1. 在 `zhCNTranslations` 对象中按命名空间分组追加键
2. 在 `enUSTranslations` 对象中**同步追加同名键**（英文翻译）
3. 在使用处用 `t('namespace.key')` 或 `t('namespace.key', { var: value })`
4. 运行 `node scripts/scan-hardcoded.mjs` 确认无新增硬编码

## 三、toast / setMessage 的 i18n 用法

### 3.1 Toast 组件支持的两种形式（见 [Toast.tsx](file:///e:/LA_DUCK/la-duck/src/components/common/Toast.tsx)）

```typescript
// 形式 1：字符串 i18n key（推荐，简洁）
addToast('toast.duckdbInitSuccess', 'success', 3000);
// Toast 组件识别为 i18n key 后自动 t() 翻译

// 形式 2：对象 { key, vars }（带变量插值时用）
addToast({ key: 'toast.duckdbInitSuccess', vars: { count: 5, ms: 120 } }, 'success', 3000);
// Toast 组件调用 t(key, vars) 翻译

// ❌ 禁止：硬编码中文字符串
addToast('DuckDB 初始化完成', 'success', 3000);

// ❌ 禁止：字符串拼接中文
addToast(`已同步 ${count} 个表`, 'success', 3000);
// ✅ 正确：
addToast({ key: 'toast.syncedTables', vars: { count } }, 'success', 3000);
```

### 3.2 setMessage 同理

`setMessage(msg, type)` 与 toast 一致，支持 i18n key 字符串或 `{ key, vars }` 对象。

### 3.3 throw new Error 的处理

- ✅ 推荐：抛出 i18n key 字符串，由调用方 `t(err.message)` 翻译
  ```typescript
  throw new Error('error.task.load_failed');
  // 调用方：
  catch (e) { setError(t(e.message), 'error'); }
  ```
- ✅ 可接受：在 store 内已有 `errorKey` 字段时，前端读 `errorKey` 走 `t()`，中文 `error` 字段仅作开发日志
- ❌ 禁止：throw 硬编码中文后直接展示给用户

## 四、硬编码检测机制（强制启用）

### 4.1 vite-plugin-hardcoded-detector

- 位置：[scripts/vite-plugin-hardcoded-detector.ts](file:///e:/LA_DUCK/la-duck/scripts/vite-plugin-hardcoded-detector.ts)
- 启用方式：在 [vite.config.ts](file:///e:/LA_DUCK/la-duck/vite.config.ts) 的 `plugins` 数组中引入 `hardcodedDetector({ baseline: N })`
- 作用：dev 模式扫描 `src/` 下 `.ts/.tsx`，发现中文 UI 硬编码时在控制台 warning；CI 模式（`strict: true`）下超 baseline 即失败

### 4.2 baseline 机制

- `baseline` = 当前已存在的硬编码数量（用于增量迁移，不阻塞已有问题）
- 新增硬编码会使总数 > baseline → CI 失败
- 修复硬编码后应同步下调 baseline，最终目标 baseline = 0

### 4.3 独立扫描脚本

- 位置：[scripts/scan-hardcoded.mjs](file:///e:/LA_DUCK/la-duck/scripts/scan-hardcoded.mjs)
- 用法：`node scripts/scan-hardcoded.mjs`
- 用途：全量扫描并输出硬编码清单（文件:行:内容），用于评估修复进度
- 排除规则：LocaleContext.tsx、`__tests__/`、`*.test.ts`、`types/`、console、注释、SQL 关键字、翻译表变量

## 五、新增 / 修改功能时的 i18n 自检清单

| 检查项 | 验证方式 |
|--------|---------|
| 新增 UI 文字是否都走 `t()` | 代码 review + `node scripts/scan-hardcoded.mjs` 无新增 |
| 新增翻译键是否中英文同步 | `LocaleContext.tsx` 中 `zhCNTranslations` 与 `enUSTranslations` 键名一一对应 |
| toast / setMessage 是否用 i18n key 或 `{key, vars}` | grep `setMessage\|addToast` 确认无中文字符串 |
| 切换中英文是否实时生效 | 应用内设置切换语言后，所有 UI 文字即时更新（LocaleContext 的 useEffect 监听 `language` 设置） |
| 变量插值是否用 `{var}` 占位符 | 翻译键内用 `{count}`，调用方传 `{ vars: { count: 5 } }` |

| 验证项 | 命令（PowerShell 环境） | 期望结果 |

### 6.1 翻译键中英文对齐检测

```powershell
cd e:\LA_DUCK\la-duck
node -e "
const fs = require('fs');
const c = fs.readFileSync('src/context/LocaleContext.tsx', 'utf-8');
const extract = (obj) => {
  const m = c.match(new RegExp('const ' + obj + ': Record<string, string> = \\\\{([\\\\s\\\\S]*?)\\\\n\\\\};'));
  if (!m) return [];
  return [...m[1].matchAll(/'([a-z][a-zA-Z0-9_.]+)':/g)].map(x => x[1]);
};
const zh = extract('zhCNTranslations');
const en = extract('enUSTranslations');
const zhSet = new Set(zh), enSet = new Set(en);
const missingEn = zh.filter(k => !enSet.has(k));
const missingZh = en.filter(k => !zhSet.has(k));
console.log('zh keys:', zh.length, 'en keys:', en.length);
console.log('en 缺失:', missingEn.length, missingEn.slice(0, 10));
console.log('zh 缺失:', missingZh.length, missingZh.slice(0, 10));
"
```
