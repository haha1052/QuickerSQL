# Checklist - 设置界面改进

## 功能验证

- [ ] 用户点击设置按钮时，弹出居中的设置子窗口
- [ ] 子窗口有明显的关闭按钮（×）
- [ ] 点击关闭按钮时，子窗口关闭，返回工作区
- [ ] 按下 ESC 键时，子窗口关闭
- [ ] 点击遮罩背景时，子窗口关闭
- [ ] 工作区在子窗口打开时保持可见

## UI 验证

- [ ] 设置界面所有字号已缩小为原来的 3/4
- [ ] 子窗口样式美观，与整体设计风格一致
- [ ] 字体缩小后不影响可读性和布局

## 功能验证

- [ ] 安全分类下显示"重启应用"按钮
- [ ] 点击"重启应用"按钮后，应用自动重启
- [ ] 重启后设置保持不变

## 翻译验证

- [ ] 中文界面下，所有设置文本正确显示中文
- [ ] 英文界面下，所有设置文本正确显示英文（包括活动记录管理、首次启动设置等）
- [ ] Settings.tsx 中不再有硬编码的中文字符串

## 技术验证

- [ ] `npx tsc --noEmit --pretty` 通过（0 errors）
- [ ] 无新增 `any` 类型
- [ ] 无新增 `@ts-ignore`
- [ ] 无新增 `console.log` 调试代码
