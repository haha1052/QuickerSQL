# 查询结果集 UI 优化修复 — Verification Checklist

## 布局修复验证
- [ ] 单行结果时，分页信息/底部内容完整可见，无遮挡
- [ ] 多行结果（超过一页）时，分页信息完整可见，无遮挡
- [ ] 结果超过 maxResultRows 有警告时，警告条完整可见，无遮挡
- [ ] 结果集顶部 header 完整可见（SQL 语句、耗时、引擎标识等）
- [ ] 结果集高度自适应，无多余空白
- [ ] 多个结果集堆叠时，各自布局正常

## 行数显示验证
- [ ] 有 SELECT 结果时，引擎标识后显示行数
- [ ] INSERT/UPDATE/DELETE 等无结果集的语句，不显示行数
- [ ] 查询失败时，不显示行数
- [ ] 行数显示格式正确（千分位分隔）
- [ ] 行数样式与整体 UI 风格统一
- [ ] DuckDB 和 SQLite 引擎下均正常显示

- [ ] 表格渲染正常，数据正确
- [ ] 表格排序正常
- [ ] 表格过滤正常
- [ ] 表格分页正常
- [ ] 表格/图表切换正常
- [ ] 导出功能正常（CSV、JSON）

- [ ] 错误结果展示正常（错误信息、定位到错误行按钮）
