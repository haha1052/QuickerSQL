# 工具栏样式与布局按钮调整 - 产品需求文档

## Overview
- **Summary**: 调整工具栏（功能栏）的高度和字体大小，使其与标签栏一致；将图表按钮替换为布局按钮，提供更实用的功能入口。
- **Purpose**: 优化工具栏的视觉一致性，减少垂直空间占用，提供更常用的布局切换功能。
- **Target Users**: 所有使用SQL查询功能的用户

## Goals
- 工具栏高度调整为与标签栏一致（32px）
- 工具栏字体大小调整为与标签栏一致（12px）
- 将图表按钮替换为布局按钮（下拉菜单，提供4种布局选项）
- 保持工具栏其他功能不变

## Non-Goals (Out of Scope)
- 不修改后端数据存储结构
- 不改变现有的SQL执行逻辑
- 不修改标签栏的功能和样式
- 不修改图表面板的功能（只是移除入口按钮，图表面板功能保留）

## Background & Context
- 当前工具栏高度约 44px（8px padding + 内容），标签栏高度 32px，高度不一致
- 当前工具栏字体大小 13px，标签栏字体大小 12px，字体大小不一致
- 当前工具栏有图表按钮，但用户更常用的是布局切换功能
- 布局切换功能已有4种选项：100%编辑器、80%编辑器/20%结果、50%编辑器/50%结果、20%编辑器/80%结果

## Layout Structure (目标布局)

```
┌─────────────────────────────────────────────────────────────────┐
│ 工具栏（32px高，12px字体）                                        │
│  [新建][打开][保存] | [运行] | [刷新][导出] |             [布局▼]      
├─────────────────────────────────────────────────────────────────┤
│ 标签栏+执行栏（32px高，12px字体）                                 │
│  [标签1][标签2][+]                                    ▶ 执行 SQL │
├─────────────────────────────────────────────────────────────────┤
│ SQL编辑器 + 结果面板                                             │
└─────────────────────────────────────────────────────────────────┘
```

## Functional Requirements
- **FR-1**: 工具栏高度调整为 32px，与标签栏一致
- **FR-2**: 工具栏字体大小调整为 12px，与标签栏一致
- **FR-3**: 将图表按钮替换为布局按钮
- **FR-4**: 布局按钮点击后显示下拉菜单，提供4种布局选项：
  - 100% 编辑器
  - 80% 编辑器 / 20% 结果
  - 50% 编辑器 / 50% 结果
  - 20% 编辑器 / 80% 结果
- **FR-5**: 点击布局选项后，仅修改当前标签页的布局
- **FR-6**: 新建标签页默认使用 100% 编辑器布局

## Non-Functional Requirements
- **NFR-1**: 布局切换应立即生效，无明显延迟
- **NFR-2**: 下拉菜单样式与整体UI风格一致
- **NFR-3**: 工具栏高度变化不影响其他组件

## Constraints
- **Technical**: React + Zustand状态管理，Tauri框架
- **Dependencies**: 现有 Toolbar 组件、workspaceStore

## Assumptions
- 布局按钮放在工具栏右侧区域，替换原图表按钮位置
- 布局下拉菜单使用简单的自定义实现，不引入新的UI库
- 图表面板功能保留，只是移除工具栏入口按钮（用户仍可通过其他方式添加图表面板）

## Acceptance Criteria

### AC-1: 工具栏高度与标签栏一致
- **Given**: 用户打开SQL查询页面
- **When**: 查看工具栏和标签栏
- **Then**: 工具栏高度为 32px，与标签栏高度一致
- **Verification**: `human-judgment`

### AC-2: 工具栏字体大小与标签栏一致
- **Given**: 用户打开SQL查询页面
- **When**: 查看工具栏和标签栏的文字
- **Then**: 工具栏字体大小为 12px，与标签栏字体大小一致
- **Verification**: `human-judgment`

### AC-3: 图表按钮替换为布局按钮
- **Given**: 用户打开SQL查询页面
- **When**: 查看工具栏
- **Then**: 工具栏中没有图表按钮，显示布局按钮
- **Verification**: `human-judgment`

### AC-4: 布局按钮显示下拉菜单
- **Given**: 用户打开SQL查询页面
- **When**: 点击布局按钮
- **Then**: 显示下拉菜单，包含4种布局选项
- **Verification**: `human-judgment`

### AC-5: 点击布局选项切换布局
- **Given**: 用户打开布局下拉菜单
- **When**: 点击某一个布局选项
- **Then**: 当前标签页的面板布局切换为对应比例
- **Verification**: `human-judgment`

### AC-6: 布局切换仅影响当前标签页
- **Given**: 用户有多个标签页
- **When**: 在某一个标签页切换布局
- **Then**: 只有当前标签页的布局发生变化，其他标签页保持不变
- **Verification**: `human-judgment`

### AC-7: 其他工具栏功能保持不变
- **Given**: 用户打开SQL查询页面
- **When**: 使用其他工具栏按钮（新建、打开、保存、运行、刷新、导出）
- **Then**: 所有功能正常工作，与之前一致
- **Verification**: `human-judgment`
