# 图表类型扩展 - Product Requirement Document

## Overview
- **Summary**: 扩展当前仪表盘支持的图表类型，从现有的 6 种（柱状图、折线图、饼图、堆叠柱状图、面积图、散点图）扩展到更多常用商业图表类型，提升数据可视化表达能力。
- **Purpose**: 当前图表类型较少，无法满足常见的数据分析场景（如转化漏斗、KPI 仪表盘、多维占比、双轴对比等）。参考主流 BI 工具（Tableau、Power BI、FineBI、Superset），补充常用图表类型。
- **Target Users**: 所有使用仪表盘进行数据可视化分析的用户。

## Goals
- 第一阶段新增 6 种高优先级常用图表（条形图、环形图、双轴图、雷达图、漏斗图、仪表盘）
- 所有新增图表支持后端自动生成配置 + 前端 ECharts 渲染
- 保持与现有图表一致的交互体验（编辑、保存、推荐逻辑）
- 不影响现有 6 种图表的功能

## Non-Goals (Out of Scope)
- ❌ 不做 3D 图表
- ❌ 不做地图/地理信息图表（需要地理数据支持，后续单独规划）
- ❌ 不做自定义图表/代码式图表配置
- ❌ 不做图表主题切换（在设置中已有配色方案）
- ❌ 不做图表联动/钻取（后续单独规划）

## Background & Context

### 当前图表类型（6 种）
| 类型 | 英文名 | 状态 |
|------|--------|------|
| 柱状图 | bar | ✅ 已有 |
| 折线图 | line | ✅ 已有 |
| 饼图 | pie | ✅ 已有 |
| 堆叠柱状图 | stackedBar | ✅ 已有 |
| 面积图 | area | ✅ 已有 |
| 散点图 | scatter | ✅ 已有 |

### 主流 BI 工具图表类型参考
- **Tableau**: 20+ 种，含条形图、双轴图、雷达图、漏斗图、箱线图、子弹图、帕累托图等
- **Power BI**: 30+ 种，含环形图、仪表盘、旭日图、树图、热力图、桑基图等
- **FineBI**: 50+ 种，含词云、关系图、地图、甘特图等
- **Superset/Metabase**: 20+ 种，含大图卡、表格透视等

### 技术现状
- 前端使用 ECharts 5.x 渲染，支持绝大多数图表类型
- 后端 Rust 生成 ECharts 配置（`chart_service.rs`）
- 图表类型枚举定义在前后端两处，需同步扩展
- 图表类型选择 UI 在两个地方：SQL 查询页 `ChartTypeSelector.tsx`、仪表盘编辑页 `ChartEditSidebar.tsx`

## Functional Requirements

### FR-1: 新增条形图（横向柱状图）
- 类别标签较长时更适合展示
- 配置逻辑与柱状图类似，仅翻转 X/Y 轴
- 支持多系列、堆叠条形图

### FR-2: 新增环形图（甜甜圈图）
- 饼图变种，中心空心
- 适用场景与饼图相同，视觉更现代
- 支持中心显示总计/指标

### FR-3: 新增双轴图（双 Y 轴）
- 左右两个 Y 轴，支持不同量级数据对比
- 常见组合：柱状图 + 折线图（如销量 + 增长率）
- 用户可指定哪些系列用左轴、哪些用右轴

### FR-4: 新增雷达图
- 多维数据对比（如能力模型、KPI 综合评分）
- 支持多个数据系列对比
- 支持设置指标名称和数值范围

### FR-5: 新增漏斗图
- 转化流程分析（如：访问 → 注册 → 付费 → 复购）
- 支持标签显示：数值、百分比
- 支持倒金字塔/金字塔样式

### FR-6: 新增仪表盘（Gauge）
- 单指标 KPI 展示（如完成率、使用率、健康度）
- 支持进度条/仪表盘两种样式
- 支持设置阈值颜色区间

## Non-Functional Requirements

- **NFR-1**: 新增图表的渲染性能不低于现有图表（单图渲染 < 200ms）
- **NFR-2**: 所有新增图表支持自适应容器大小
- **NFR-3**: 向后兼容：旧数据/旧图表不受影响
- **NFR-4**: 推荐图表逻辑同步更新（根据数据类型推荐合适的新增图表）

## Constraints
- **技术**: 前端基于 ECharts 5.x，后端 Rust 生成配置
- **业务**: 第一阶段只做最高频使用的 6 种，控制在合理工作量内
- **依赖**: 仅依赖已有的 ECharts 库，不引入新的第三方图表库

## Assumptions
- 用户对图表类型的需求集中在常见的 10-15 种，长尾类型使用频率低
- ECharts 已内置支持所有计划新增的图表类型，无需额外插件
- 后端生成配置的模式（参数化 + 数据映射）可复用到新增图表类型

## Acceptance Criteria

### AC-1: 条形图正常使用
- **Given**: 用户在 SQL 查询页执行了一条有类别列和数值列的查询
- **When**: 用户选择"条形图"类型，配置 X 轴和 Y 轴
- **Then**: 正确渲染横向条形图，可保存到图表库，可添加到仪表盘
- **Verification**: `human-judgment`
- **Notes**: 多系列时并列显示，堆叠条形图也需支持

### AC-2: 环形图正常使用
- **Given**: 用户有一组占比数据
- **When**: 用户选择"环形图"类型
- **Then**: 正确渲染环形图，中心可选显示总计
- **Verification**: `human-judgment`

### AC-3: 双轴图正常使用
- **Given**: 用户有两个不同量级的数值列
- **When**: 用户选择"双轴图"类型，并指定左轴/右轴系列
- **Then**: 正确渲染双 Y 轴图表，左右轴刻度独立
- **Verification**: `human-judgment`

### AC-4: 雷达图正常使用
- **Given**: 用户有多维指标数据
- **When**: 用户选择"雷达图"类型
- **Then**: 正确渲染雷达图，支持多系列对比
- **Verification**: `human-judgment`

### AC-5: 漏斗图正常使用
- **Given**: 用户有序列化的转化阶段数据
- **When**: 用户选择"漏斗图"类型
- **Then**: 正确渲染漏斗图，显示各阶段数值和转化率
- **Verification**: `human-judgment`

### AC-6: 仪表盘正常使用
- **Given**: 用户有一个百分比/数值指标
- **When**: 用户选择"仪表盘"类型
- **Then**: 正确渲染仪表盘，显示数值和进度
- **Verification**: `human-judgment`

### AC-7: 向后兼容
- **Given**: 已有 6 种图表类型的保存数据
- **When**: 升级后打开旧图表
- **Then**: 旧图表正常渲染，无报错
- **Verification**: `programmatic`（TypeScript 编译通过 + Rust 测试通过）

### AC-8: 图表选择器 UI 完整
- **Given**: 打开图表类型选择界面
- **When**: 查看所有可用图表类型
- **Then**: 显示所有 12 种（原有 6 + 新增 6），布局美观不拥挤
- **Verification**: `human-judgment`

## Open Questions
- [ ] Q1: 双轴图的系列分配是自动判断还是用户手动选择？（建议：自动 + 可手动调整）
- [ ] Q2: 仪表盘的阈值颜色区间是否需要用户可配置？（建议：默认三色区间，高级配置后续做）
- [ ] Q3: 漏斗图是否需要支持对比漏斗（两个漏斗并排）？（建议：第一阶段先做单漏斗）
- [ ] Q4: 图表类型选择器是分类展示还是全部平铺？（建议：12 种可以平铺，再多再分类）
