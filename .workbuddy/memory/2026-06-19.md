# 2026-06-19 Daily Memory

## Bug 修复：仪表盘图表渲染失败（两连修）

### Bug 1：snake_case vs camelCase 字段名不匹配
- 后端 `EChartsConfig` 字段 snake_case，ECharts 需要 camelCase → 添加 `#[serde(rename)]`
- 修改文件：`chart_service.rs`、`tauri.ts`、`ChartRenderer.tsx`

### Bug 2：仪表盘显示"数据加载失败"，控制台报 `get_saved_query: failed: 查询不存在`

**根因链路：**
1. savedChart.sql 为空 → `hasSql = false`
2. 走回退逻辑 → `get_saved_query(queryId)` → __saved_queries 中找不到
3. **代码完全忽略了 savedChart.config 可直接渲染**

**修复：三层降级策略**
```
策略 1（最优）：savedChart.config 存在且有效 → 直接 setOption（无需 SQL）
策略 2（标准）：sql + xAxis/yAxis 完整 → renderWithSql 重新生成配置
策略 3（回退）：queryId 在 __saved_queries 中找到 → 用回退 SQL 渲染
全部失败 → 报错并提示缺失字段
```

**修改文件：** `src/components/dashboard/DashboardItem.tsx` — 重写渲染逻辑

### 关键经验
- SavedChart.config 是完整的 ECharts 配置对象，是渲染的"黄金数据"
- SQL + xAxis/yAxis 只是**重新生成** config 的参数，不是唯一渲染路径
- 仪表盘应优先用 config 直接渲染，SQL 路径只是备选

## Bug 4 修复：仪表盘"添加图表"按钮无反应 + 空状态无法添加

### 问题现象（用户截图）
1. 仪表盘显示"暂无图表"空状态
2. 点击"+ 添加图表"按钮完全无反应
3. 图表库面板也没有预览功能（上一轮已修复）

### 根因分析（关键发现）
**`DashboardCanvas.tsx` 的致命 bug：**
```tsx
// 当 layout 为空时的 return 分支（第 31-43 行）：
if (dashboard.layout.length === 0) {
    return (
      <div style={styles.emptyCanvas}>
        ...
        <button onClick={() => setShowAddModal(true)}>+ 添加图表</button>
        {/* ⚠️ AddChartModal 不在这里！ */}
      </div>
    );
}

// AddChartModal 只在下面这个分支里（第 77-83 行）：
return (
    <div style={styles.canvas}>
      {dashboard.layout.map(...)}
      {showAddModal && <AddChartModal ... />}  {/* 只在非空时才渲染！ */}
    </div>
);
```

当 `dashboard.layout.length === 0` 时：
1. 第一个 `return` 被执行，渲染空状态 UI
2. 按钮点击 → `setShowAddModal(true)` ✓
3. **但 AddChartModal 根本不在 DOM 中！** → 用户看到"没反应"

### 修复内容

#### 1. DashboardCanvas.tsx — 将 AddChartModal 移入空状态分支
- 在空状态的 return 中也渲染 `<AddChartModal />`
- 现在无论 layout 是否为空，点击"添加图表"都能正确打开弹窗

#### 2. AddChartModal.tsx — 防御性修复 + UX 改进
- **修复潜在崩溃：** `{chart.tags.join(',')}` → `{(chart.tags || []).join(',')}` 防止 tags 为 null 时崩溃
- **UX 改进：** 当 savedCharts 为空时显示操作引导：
  > 如何添加图表到仪表盘？
  > 1. 进入「SQL 查询」页面
  > 2. 执行 SQL 查询并生成图表
  > 3. 点击「保存图表」按钮
  > 4. 返回仪表盘，点击「添加图表」

#### 3. DashboardCanvas 空状态提示文案优化
- "在 SQL 查询中保存图表后，可在此处添加" → "点击下方按钮添加已保存的图表，或先到 SQL 查询页保存图表"
