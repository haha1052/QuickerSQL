# 2026-06-21 工作日志

## 修复启动椭圆外白色背景问题

### 问题描述
应用启动时，椭圆浮动卡片（380×380）外的区域（400×400 窗口减去椭圆后的环形区域）显示为白色，而非透明桌面背景。Trae 反复修改未能解决。

### 根因分析（三个叠加原因）

1. **`tauri.conf.json` 中 `backgroundColor: "#00000000"` 干扰 `transparent: true` 的分层窗口机制**
   - Tauri 2 在 Windows 上设置 `backgroundColor` 后可能不走分层窗口（layered window）路径
   - 即使 A=00（全透明），某些 Windows 合成路径下仍渲染为白色
   - 修复：移除 `backgroundColor` 字段，让 `transparent: true` 完全控制

2. **`apply_borderless()` 用 `GetForegroundWindow()` 取 HWND 不可靠**
   - setup 阶段窗口可能还不是前台窗口，`DwmExtendFrameIntoClientArea(-1)` 未生效
   - 修复：新增 `apply_borderless_to_hwnd(hwnd)` 函数，在 setup 中通过 `window.hwnd()` 获取确切 HWND

3. **index.html 定义了 `.startup-phase` CSS 类但 JS 中从未添加到 DOM**
   - 额外的 `!important` 透明保障层缺失
   - 修复：在 `<script>` 开头立即给 html/body/#root 添加 `.startup-phase` 类，splash 淡出时移除

### 修改的文件

- `src-tauri/tauri.conf.json` — 移除 `backgroundColor: "#00000000"` 字段
- `src-tauri/src/commands/startup.rs` — 新增 `apply_borderless_to_hwnd(hwnd)` 函数
- `src-tauri/src/lib.rs` — setup hook 中用 `window.hwnd()` 获取确切 HWND，立即应用边框消除 + DWM 扩展帧
- `index.html` — JS 开头添加 `.startup-phase` 类到 DOM；`__TRIGGER_SPLASH_TRANSITION__` 中移除该类

### 验证结果
- Rust 编译通过（仅 3 个无关 warning）
- TypeScript 编译通过
- 应用成功启动，诊断日志确认：HWND 获取成功 → 边框消除应用成功 → 延迟二次边框消除也应用成功
- 应用保持运行（PID 6428，53.2 MB）

### 技术要点
- Tauri 2 中 `HWND` 类型是 `windows::Win32::Foundation::HWND`，底层是 `isize`，用 `hwnd.0 as *mut std::ffi::c_void` 转换
- `log` crate 未初始化 logger，`log::info!` 不会输出到 stdout，调试时需用 `println!`
- `DwmExtendFrameIntoClientArea(-1)` 让 DWM 把整个窗口视为客户区，不绘制框架轮廓
