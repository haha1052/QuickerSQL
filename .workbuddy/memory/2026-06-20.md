## P0+P1 修复：仪表盘编辑模式拖拽/缩放/UX

### 问题
用户反馈编辑模式无法自由移动和编辑图表。全面诊断后发现 5 个问题，本次修复了前 3 个（P0+P1）。

### P0-1 修复：拖拽功能
**根因：**
1. `DashboardItemContent` 重复设置了 gridStyle（gridColumn/gridRow），导致 Grid 布局嵌套冲突
2. 外层 onMouseDown 与内部 ECharts 鼠标事件竞争 —— 点击图表区域无法开始拖拽
3. onClick 与 onMouseDown 在同一元素上竞争

**修复方案（重写 DashboardItem.tsx）：**
1. 将 `DashboardItemContent` 重命名为 `ChartCanvas`，移除其重复的 gridStyle/item 样式/toolbar，只负责 ECharts 渲染
2. 编辑模式下 ChartCanvas 设置 `pointerEvents: 'none'`，让鼠标事件穿透到外层卡片
3. 增加 `DRAG_THRESHOLD_PX = 5` 阈值：鼠标移动超过 5px 才认为是拖拽，否则视为点击
4. 拖拽开始后才设置 `isDragging` 状态，拖拽中禁用文本选中 + 设置 body cursor
5. onClick 中检查 `!isDragging` 才触发选中，避免拖拽结束后误触发选中

### P0-2 修复：缩放手柄可见性
**根因：** resizeHandleRight/Bottom 的 `background: 'transparent'` 且只有 8px，用户看不到。

**修复方案：**
1. 在 `App.css` 添加 `.resize-handle-right:hover` / `.resize-handle-bottom:hover` 高亮效果（`background: var(--primary)`）
2. 手柄宽度从 8px 调整为 6px（right/right `-2px` 定位），保持精准但 hover 时高亮可见
3. corner 手柄保持 16px 蓝色圆点不变

### P1 修复：编辑模式 UX + 布局保存
**修复方案：**
1. **编辑模式提示条**：DashboardPage 在编辑模式下显示蓝色 banner："✏️ 编辑模式 — 拖拽图表卡片移动位置，拖拽右下角蓝色圆点调整大小"，并显示已修改项数
2. **卡片内提示**：DashboardItem 左上角显示"✋ 拖拽移动"提示
3. **虚线边框**：编辑模式下卡片使用 `border: 2px dashed var(--primary)` + `cursor: move`
4. **退出确认**：退出编辑模式时，如有修改则弹出确认对话框
5. **并行保存**：`handleToggleEdit` 从串行 for 循环改为 `Promise.all` 并行 + 错误收集，失败项显示警告
6. **拖拽视觉反馈**：拖拽中卡片半透明 + 阴影 + z-index 提升

## P2+P3 实施：筛选器联动 + 键盘快捷键 + PNG 导出（续）

### P2-1 筛选器联动（已完成）
**方案：** 新建 `src/utils/filterSql.ts`，将 filterValues 转 SQL WHERE 注入查询。
- 支持 text（LIKE）、select（= / IN）、date-range（BETWEEN）
- DashboardItem 从 store 获取 filterValues + dashboardFilters
- useEffect 依赖增加 `filterValuesKey`（JSON.stringify），筛选变化触发重新渲染
- 筛选激活时跳过 config 直渲，强制走 SQL 路径
- 字符串值转义单引号防注入

### P3-3 键盘快捷键（已完成）
DashboardPage 添加 keydown 监听（编辑模式下生效）：
- `Delete/Backspace`：删除选中图表（带确认）
- `方向键`：微调选中图表位置（Shift = 3格大步，普通 = 1格）
- `Esc`：退出全屏 / 退出编辑 / 取消选中（三级优先级）
- 输入框中不触发快捷键
- 编辑 banner 显示快捷键提示

### P3-1 PNG 导出（已完成）
**方案：** 新建 `src/utils/dashboardExport.ts`，无额外依赖。
- ChartCanvas 容器添加 `data-echarts-container` 标记
- 导出时用 `echarts.getInstanceByDom()` 获取所有实例
- 调用 `getDataURL()` 获取各图表 base64
- 按网格布局绘制到一张 Canvas（2x 分辨率）
- 圆角卡片背景 + 边框
- DashboardToolbar 添加"📷 导出"按钮（编辑模式禁用）
